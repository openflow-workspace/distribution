# AI agent platform

* [AI agent platform epic](ai-agent-platform.md) - Agent platform acting on behalf of the logged-in user, preferably via MCP.
* [Delegated user identity](ai-agent-delegated-identity.md) - Agent actions run with the identity and permissions of the logged-in user.
* [MCP access](ai-agent-mcp-access.md) - Expose openDesk services to the agent platform via MCP, starting with search.
* [RAG foundation](ai-agent-rag.md) - RAG layer over openDesk content for the agent platform.
* [AI-capable interfaces](ai-agent-ai-capable-apis.md) - APIs on the services suitable for AI/agent use.
